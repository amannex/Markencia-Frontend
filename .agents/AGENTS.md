# Project Agent Rules

## Git & Version Control Workflow
- **Do not create a new git branch automatically** for changes or edits. Stay on the current active branch unless explicitly asked by the user to create a new branch.
- **Do not automatically open the browser** to check changes after every edit unless explicitly asked.
- **Do not push changes automatically to remote (`origin`) every time.** Only create local commits (`git commit`) after making edits. Only push when explicitly instructed by the user.
